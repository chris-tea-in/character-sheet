# Contributing

Use Node.js and `npm ci`, then run `PUBLIC_BUILD_MODE=1 npm run build`, `npm run test`, and `npm run typecheck:functions` before proposing a change. The public build mode intentionally contains no reference catalog content.

Keep public changes free of personal machine paths, internal agent files, customer data, credentials, and production infrastructure details. Follow the security policy for vulnerability reports.

This repository does not grant a software license; reuse permissions are not part of this contribution scope.
